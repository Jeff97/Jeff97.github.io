# SCUT Wushan campus map

Source: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright (ODbL).
Retrieved 2026-09-08 via https://www.openstreetmap.org/api/0.6/map?bbox=113.340,23.147,113.350,23.155

The SVG contains simplified building, road and water geometry, recolored for the home page. It is a local asset; no visitor requests to a map API are needed.

The marker indicates the approximate southern campus vicinity, not a surveyed building coordinate. The official campus map places the Transportation Building near the south-side entrance:
https://sce.scut.edu.cn/_upload/article/files/47/ad/a0ecf2664efa85a186f88904e783/6f3db12d-c658-44b6-b960-0da068fe01b6.pdf

The link searches Amap for the full building name rather than passing an unverified coordinate. Once a verified building coordinate is available, update the marker position; keep coordinate systems consistent (OSM uses WGS84, Amap uses GCJ-02).
